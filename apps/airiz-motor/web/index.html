          AIRIZ CONSOLE · USER GUIDE

          One console for the whole AIRIZ bench.

          Motor jogging, the firmware command library, macros, the device camera, sound and phone sharing in one app. It replaces the old TeraTerm/CWD serial workflow.

          Owner
          Juwen Lie
          Team
          Ziris PTB (co-admins)
          Editions
          Windows desktop app · browser (Chrome/Edge) · Android · iPhone via Bluefy

          1 Getting started

          1. Use the Windows desktop app (recommended) or open the console in Chrome or Edge. Other browsers can only run the demo.
          2. Plug the AIRIZ in with the FT232R USB-serial cable and press Connect. Pick the port; the baud rate is 115200 unless told otherwise.
          3. Wait until the device answers (prompt ~ # in the console). Motor controls unlock only after the firmware replies.
          4. No hardware? Press Try demo to explore every page with a simulated device; nothing moves.

          2 Motor control

          • Each click on the jog pad (or arrow key) sends one finite jog – pan left/right, rising up/down. Nothing runs continuously.
          • Set Speed / strength (pan 1–17, rising 1–30, firmware scale, not RPM) and Steps, or use the Fine/Medium/Coarse presets.
          • The switch next to the pad locks new jogs; Stop motor (or Esc) stops a move already running.
          • The device picture is a command visualisation, not position feedback.

          3 Commands & macros

          • Command library: search every diagnostic command, fill in parameters and press Send. Reboot-type commands ask first.
          • Live console: type raw commands (Enter sends), filter, clear and Save Log to a timestamped text file.
          • Macro studio: pick a built-in macro (the original TeraTerm test_motor macros are included) or build your own with Blank, Command, Wait, Pause and Note steps, set Repeat and press Run. Save As keeps your macro; Export .ttl gives TeraTerm code.
          • Stop ends the macro schedule; it does not stop a motor move already sent – use Stop motor for that.

          4 Camera

          • Open the camera panel, choose the AIRIZ UVC camera and a mode, then Start Preview.
          • Capture full-resolution stills, take snapshots, record video, or start a session folder that collects everything for one test.
          • Day/Night & Lights switches the IR-cut, IR LED and spot LED and reads the ALS sensor. Daylight fix turns the lights off and sets Day mode in one click.
          • PTZ live view: click the picture to center that spot, hold an arrow to move (release = stop) and use the wheel for digital zoom. Set Home, soft limits and up to 12 saved positions; Auto scan visits them in turn.
          • Smart detection watches the preview for motion inside your zones and active hours, saves a photo and a 10 s clip, and can follow the motion, turn the spotlight on, sound the siren, show a desktop notification or alert the Ziris PTB chat. It runs while the console is open.
          • Privacy lowers the camera to the rising switch and turns the lights off; automatic night vision switches IR-cut and IR LED from the light sensor. The motors report no position, so positions are counted in steps: calibrate once per device under Calibration.

          5 Share the camera to a phone

          1. On the PC: press Remote by code (start screen) or Share control (Motor page). One 6-digit code shares the motor and the camera; the camera preview starts by itself.
          2. On the phone: open the AIRIZ console → Remote by code → type the code (or Camera → enter the code → Watch to only watch).
          3. The viewer list shows who is watching. Behind a company firewall the picture comes through the AIRIZ relay as quick snapshots.
          4. Keep the PC window open while sharing; Stop sharing ends it and the code stops working.

          6 Ziris PTB Teams auto-post

          For Ziris PTB co-admins only. When you share with Remote by code or Share control, the code is posted straight to the Ziris PTB group chat in Microsoft Teams, so whoever holds the phone just opens Teams and taps Open AIRIZ console. Nobody has to read the number off the screen.

          Co-admins: join once

          1. In the Ziris PTB Teams chat press Join Ziris PTB on the invite from Juwen Lie. The invite opens in the browser.
          2. Type your name and press Join Ziris PTB. That is all: everybody is a Co-admin.
          3. Using the AIRIZ Windows app? On the same page press Open in the AIRIZ Windows app and allow the browser to open it: the app joins with the same name. (Or paste the invite link in the app's Ziris PTB team page.)
          4. Press Send test message once and check the chat.
          5. From now on every share code is sent automatically, one message per code. The Share control window confirms it (“Code … sent to Ziris PTB”). If it fails, press Send to Teams there to retry.
          6. Controllers still need the PC operator to press Allow.

          Owner: one-click setup

          1. Once in Teams: add Send webhook alerts to a chat for Ziris PTB, authorize it and copy the workflow address. Use an Anyone trigger only if your organization permits private bearer webhooks.
          2. Ziris PTB team → Finish owner setup. The button uses your saved owner address or the one you copied; pasting it first also works.
          3. The console submits one shared Co-admin invite, sets up Juwen Lie as Owner on this PC, enables auto-post and copies the invite link. Check the Teams chat to confirm delivery; workflow acceptance alone is not delivery confirmation.
          4. Next launch: your owner setup is restored in the same app/browser, with no repeated invite and no clipboard reading. If you turned auto-post off, it stays off until you enable it.
          5. If setup fails, your previous team settings are kept. Check Teams before retrying a timed-out request. Manual invite and resend controls remain under Advanced: personal invite or resend.
          6. To revoke access, replace the workflow and run owner setup with the new address.

          Without an invite the app never sends anything to Teams. Keep the invite inside the Ziris PTB chat – do not post it in public channels. Messages contain only the code, the public watch link, the member name and the PC name.

          7 Remote control by code

          1. On the PC connected by USB: Share control → a 6-digit code appears.
          2. On the phone or another PC: Connect by code → enter the code.
          3. The PC operator presses Allow, or Allow & remember to let that phone in by itself next time (switch that off, or Forget a phone, under Remembered devices). Several phones can control at the same time; the PC can disconnect any of them, and a phone that drops right after a motor command triggers a motor stop.
          4. While sharing, the Windows app keeps the PC awake, also on battery, and closing the lid does not stop the share. Your own power settings come back when you stop sharing or close the app.
          5. If the PC still sleeps (Sleep or power button) or the network drops, the code stays the same and the phones keep reconnecting by themselves until you stop sharing, also after the console restarts for an update or a phone reloads the page. A dropped AIRIZ USB link reconnects by itself too.

          8 Phone remote (Bluetooth)

          1. Connect the device over USB → Phone remote → Start remote (shows a PIN). Repeat after every power-up.
          2. Android: AIRIZ Mobile app or Chrome. iPhone: the free Bluefy browser → this console → Connect Bluetooth → AIRIZ-BT → PIN.
          3. Bluetooth on in the status bar is only a firmware test; it does not let the phone see the device.

          9 Device audio

          • Play test WAV (Commands & macros → Audio) plays the built-in test WAV on the AIRIZ speaker; Set volume sets the level (0–100).
          • With Auto-save recording on, every DMIC record is pulled from the device and saved as dmic_<date-time>_<seconds>s_<gain>.wav.

          10 Troubleshooting

          No port in the Connect list
          Check the cable and the FTDI driver; close TeraTerm or any other program that holds the COM port.
          Phone says “No PC is sharing with that code”
          The PC stopped sharing or the preview stopped. Share again and use the new code.
          Phone finds the PC but no video
          A firewall blocks WebRTC. Update the PC console to the latest version (relay fallback) or put both on the same Wi-Fi.
          Code not posted to Teams
          Open Ziris PTB team: you need to join the team and switch auto-post on. Send test message shows the exact error. If the owner replaced the workflow, ask for a new invite link.
          Motor does not stop with the macro Stop
          Macro Stop only stops scheduling; press Stop motor or Esc.
