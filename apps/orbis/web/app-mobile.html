Orbis Work

[FUTURE VISION] Planned module — not in first release

[FUTURE VISION] Planned module

Scope, pricing and launch are not decided. This view shows the intended design for matching people with roles based on skills and experience only — never personality ranking.

How it works

1. Build profile
Portfolio and Aura, chosen by you
2. Post or search
Roles with stated requirements
3. Match on skills
Experience and requirements only
4. Introduce
Both sides accept
5. Chat
Direct conversation
6. Decide
Human review, both can end or report

Fairness rules

  • No personality ranking — Aura never ranks, filters or rejects candidates.
  • Matching criteria — skills, experience and stated requirements only.
  • Context, not scoring — profiles provide context for human decisions.
  • Human decisions — hiring decisions are made by people, with the reason visible.
  • Exit — either side can end, report or delete.
