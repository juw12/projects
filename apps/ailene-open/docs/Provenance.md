# Provenance: Ailene Open

## Statement of Independence

**Ailene Open is an independent, open-source educational project.**

It is **NOT** affiliated with, endorsed by, or connected to:
- **ailene.id** (the Indonesian AI learning platform)
- **PT Pengusaha Muda Indonesia** (the company behind ailene.id)
- Any other commercial AI education provider

## Purpose

This project exists to:
1. Provide a **vendor-neutral** alternative to platform-specific AI courses
2. Offer **free, open access** to AI fundamentals (no paywalls)
3. Teach **transferable concepts** that work across all AI models
4. Serve **Indonesian and English** learners equally
5. Enable **offline learning** for users with limited connectivity

## What This Is

- ✅ An independent reinterpretation of AI learning best practices
- ✅ A demonstration of offline-first, zero-dependency web architecture
- ✅ A bilingual (ID/EN) educational resource
- ✅ An open-source curriculum with citable sources
- ✅ A vendor-neutral prompt library

## What Was Observed from ailene.id

The following **high-level observations** informed this project's design:

### Structural Observations
- 12-question "AI type" quiz with 5 personas (Professor/Builder/Detective/Guardian/All-Rounder)
- Level-based curriculum structure (Level 01: AI Fundamentals)
- Module/lesson hierarchy
- Paid packages (KelasClaude, BelajarVibeCoding, JagoHermes)

### Feature Observations
- Free tier: Level 01 (first lesson no login, rest require login)
- Paid tier: Advanced content gated behind Rp 1,49jt payment
- Discord community for paid users
- "Peta kerja" (work map) feature
- Goakal/Flip payment integration

### Design Decisions Inspired by Observations
- **Observation:** ailene.id is Claude-centric → **Decision:** Ailene Open is vendor-neutral
- **Observation:** Advanced content is gated → **Decision:** All content is free
- **Observation:** Indonesian-only → **Decision:** Bilingual ID/EN
- **Observation:** Login required for progress → **Decision:** localStorage, no login
- **Observation:** Requires network → **Decision:** Offline-first, `file://` compatible
- **Observation:** No cited sources → **Decision:** Every lesson has sources
- **Observation:** Safety not prominent → **Decision:** Dedicated safety checklist

## Fair Use Considerations

This project relies on the following fair use principles:

### 1. Educational Purpose

### 2. Transformative Use
