# ProjectSettings notes

The `Packages/manifest.json` and `ProjectSettings/ProjectVersion.txt` are the
only committed ProjectSettings files. Everything else in `ProjectSettings/` is
auto-generated by Unity the first time the project is opened (it knows which
asset to use because `manifest.json` declares HDRP as the render pipeline).

If you want to commit more ProjectSettings for reproducibility (e.g.
GraphicsSettings.asset for HDRP defaults, QualitySettings.asset for tier
settings), do it after the first open and a known-good build, then commit the
specific files you care about.
