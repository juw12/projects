✦ Set up Glow

Every Glow app, in one step.

All Glow apps are free and run in your browser. Installing just gives them their own windows and icons, and adds Glow Hands so GlowLead can use a web browser for you.

Windows PC

Master installer: all apps + Glow Hands

  1. Press Win + R, paste this line and press Enter. No admin rights needed.
powershell -ExecutionPolicy Bypass -c "irm https://raw.githubusercontent.com/juw12/projects/main/apps/glow/install-glow.ps1 | iex"
  • Glow, GlowLead, GlowChat, GlowRoom in the Start menu (folder “Glow”) and on the desktop. They open as app windows of Edge or Chrome with your normal browser profile, so they share one Glow account, your chats and missions.
  • Glow Hands installed or updated: GlowLead's browser control on this PC. It starts at every login and GlowLead connects to it by itself.
  • Run it again any time to update. Python 3.13 is added for you if it is missing.
Options and uninstall

Set an option first, in the same Win+R line, e.g. $env:GLOW_SKIP_HANDS='1'; irm …/install-glow.ps1 | iex:

  • GLOW_SKIP_HANDS=1: only the app shortcuts, no Glow Hands
  • GLOW_NO_DESKTOP=1: Start menu only
  • GLOW_UNINSTALL=1: remove the shortcuts and Glow Hands (your chats stay in the browser)
powershell -ExecutionPolicy Bypass -c "$env:GLOW_UNINSTALL='1'; irm https://raw.githubusercontent.com/juw12/projects/main/apps/glow/install-glow.ps1 | iex"
Android

Glow app

GlowLead as a real app with its own built-in browser: browser missions run on the phone itself, no PC needed.

Download Glow-android.apk

Open the file and allow “install unknown apps” for your browser once. GlowChat and GlowRoom: open them in Chrome and choose Add to Home screen.

iPhone · iPad

Add to Home Screen

  1. Open juw12.github.io/projects/glow in Safari or Chrome.
  2. Tap Share → Add to Home Screen. Repeat for GlowLead, GlowChat and GlowRoom.
  3. For browser missions, in GlowLead open Glow Hands → Connect browser control and pick Start instant cloud browser, or link your PC (below).

A native iPhone app isn't available (it needs Apple's paid developer program).

Mac · Linux

Install from the browser

Open each app in Chrome or Edge and click the Install icon in the address bar (or use the Install buttons on the Glow home).

Always-on Glow Hands for a Linux machine (Ubuntu, Raspberry Pi, a free cloud VM). It prints a QR code for your phone:

curl -fsSL https://raw.githubusercontent.com/juw12/projects/main/apps/glow/hands/install-glow-hands-linux.sh | bash

Glow Hands isn't packaged for Mac yet; use the instant cloud browser or link a Windows/Linux PC.

Phone + PC

Use your PC's browser from your phone

  1. On the PC (after the master installer), open GlowLead → Glow Hands → Use from your phone.
  2. Scan the QR code with your phone. GlowLead on the phone now drives the PC's browser.
  3. Approvals (submit, buy, send, delete) pop up on the phone; passwords you type yourself.
