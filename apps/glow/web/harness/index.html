          What it can't do

          • It cannot touch your files, run programs or browse the web. Its tools are the ones listed above and nothing more. For real work on a computer, use Claude Code, Codex or OpenCode.
          • With no model it only understands plain English requests about sums, dates, units, text and notes. For anything else it says it cannot answer, and it is right.
          • The free models are small, rationed and sometimes wrong. A long task can stall while a provider makes it wait.
          • With the free model, your task and every tool result are sent to a free AI provider. With no model, nothing leaves this page.
          • The gate stops actions you did not approve. It cannot make a wrong answer right, and it cannot tell that a model has been fooled. It only makes sure a fooled model cannot save or delete without your yes.
          • GlowSpark is a tool here, not the brain. It writes tales and cannot follow instructions.

          Built from scratch

          1. The loop: ask the brain for one step, read it, run a tool, show the result, repeat. It stops at a step limit, a time limit, a repeated call, or when you press Stop.
          2. The reader: small models write tool calls badly. The reader repairs the common ways they break. When it cannot, it tells the model exactly what was wrong and asks again.
          3. The gate: reading is allowed, while saving, deleting and downloading ask first. Once a run has read untrusted text, every such action asks again. With nobody there to ask, the answer is no.
          4. The trace: every step is recorded with its time. Replay runs the engine again on the recording and checks that it makes the same decisions.

          Use it in another Glow app

          The engine and the tool kit are two plain script files with no dependencies. Any Glow page can load them, give the harness a brain, some tools and a way to ask the user, and run a task.

          <script src="../shared/glow-harness.js"></script>
<script src="../shared/glow-harness-kit.js"></script>

const harness = GlowHarness.createHarness({
  brain: GlowHarnessKit.rulesBrain(),
  tools: GlowHarnessKit.createTools({ storage: localStorage }),
  confirm: async (request) => "deny",
  onEvent: (event) => console.log(event.type, event),
});
const result = await harness.run("Convert 26.2 miles to km.");
console.log(result.status, result.answer, result.trace);

          GlowHarness can be wrong, most of all with a free model behind it. With no model, nothing you type leaves this page. With the free model, your task and the tool results go to a free AI provider, so do not type anything private there. Notes are kept in this browser only.
