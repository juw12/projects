    What it can and cannot do
    
    
    Stated plainly, so nobody is misled.
    
    
      
      
    • A program here cannot read files, use the network or touch this page. It can only compute and print.
      • 
      
    • Every run has a work limit and a memory limit. A loop that never ends is stopped, and the Stop button works at any time.
      • 
      
    • Kilat is a small, new language. It has no packages, and it is not a replacement for Python at general work.
      • 
      
    • The free models are often wrong about Kilat. Their program is checked before it runs, and a refused program is sent back for up to two more tries. A program that passes the check can still work out the wrong thing: read it before you trust the answer.
      • 
      
    • How often a free model writes a correct program has not been measured.
