# Glow: Product Brief

## Direction
From a spark to something real: a companion for ideas, plans and practical next steps.

## Implemented prototype
- Chat with an optional second opinion from another model.
- Council: two or three role-based agents, followed by a Judge summary.
- Arena: compare model responses and record preferences.
- Text/code attachments, search, Markdown export, browser-local history and an installable PWA.
- Demo mode uses labeled canned replies; real generation needs a connected provider.

## Boundaries
This rename does not add live resource search, verified citations or autonomous building.
Resource recommendations from connected models need independent checking. Consensus and
confidence labels are model opinions, not proof of correctness. Free models retain provider limits.

## Future work
Verified resource discovery and traceable sources; reviewable project plans; human-approved
build actions. These are planned directions, not shipped capabilities.

## Hosting
The free prototype runs on GitHub Pages. An optional subscription backend exists separately,
but it has not been validated for a production paid launch.

## Name
Renamed from Mufakat to Glow with the owner's approval of known brand conflicts.
No trademark clearance is claimed.
