Install Hazel

One icon for all three Hazel apps. It opens Hazel home; long-press (or right-click) the icon for shortcuts straight into Hazel Shorts, Hazel Sped or Hazel Long.

Open in the browser

Your browser didn't offer an install prompt. Use its menu: Install app (Chrome/Edge) or Share → Add to Home Screen (Safari).

  • Hazel Shorts and Hazel Sped also install on their own from their pages.
  • Hazel Long has a Windows desktop app for auto-cutting footage.
  • Everything stays in this browser — no account needed.
