Welcome to Vertex

Vertex is a local, offline 3D engineering copilot for CAD repair, assembly, and simulation. Works fully offline · Deterministic results · Review-gated changes

Quick Start

  1. 0 1 Load a sample: Switch to Repair tab → click "Load Sample"
  2. 0 2 Read Diagnosis + Plan: Review findings and proposed repairs
  3. 0 3 Dry-run, then Apply: Click "Dry-run", tick the confirm box, then "Apply"
  4. 0 4 Build & Export: Switch to Build tab → create a part → Export (STL/OBJ/glTF/3MF/DXF)

Workspaces

Repair Diagnose broken models and plan fixes
Assembly Plan parts, mates, and validation checks
Build Parametric part design → export to CAD formats
Simulate Kinematic motion, mass properties, clearance analysis
Answers Ask questions about your design with evidence
Reverse Scan point cloud → fit to parametric CAD
Drawing 2D drawing spec → 3D model generation
Automation Batch export, patterns, and sheet operations

Good to Know

  • Offline first: Works fully offline — no internet required
  • Local bridge optional: Connector status shows adapter availability
  • Simulation mode: Nothing is written to CAD — dry-run only
  • Universal adapters: Templates for Fusion/SOLIDWORKS/FreeCAD/Blender — no host here
