How to use

  • Start a 25-minute work session. When it completes, a short 5-minute break begins automatically (if auto-advance is on).
  • After 4 work sessions, you'll get a long 15-minute break.
  • Each completed work session counts toward your daily goal. Your focus score (0–100) reflects progress toward that goal.
  • All data is saved locally in your browser. No network calls, no accounts, no tracking.
Note: This is the browser version. The full desktop app (Python + tkinter, always-on-top, with soundscapes and live app tracking) lives at index.html and on GitHub.
Web version — runs in any modern browser, works offline, zero dependencies.
