# Sweep for Android and iPhone

Capacitor 8 shells around the live phone layout (`https://juw12.github.io/projects/sweep/mobile.html`).
The app loads the site, so features and fixes arrive without a new app release; projects stay on the
phone (or sync through the user's own Gist, as on the web).

What the shell adds (detected by `web/native.js` through `window.Capacitor` and the `SweepApp/1.0` user agent):

- **Files:** WebViews ignore `<a download>`, so every export is written to the app cache
  (`@capacitor/filesystem`) and handed to the share sheet (`@capacitor/share`): save to Files or Drive,
  send to Slack, open in another app.
- **Android Back** closes the open sheet or dialog, then returns to the catalog, then leaves the app.
- **Haptics** on primary actions (`@capacitor/haptics`).
- **Update prompt:** compares the installed version (`App.getInfo`) with `web/shell.json` and offers the new APK.
- Brand icon (adaptive on Android), burgundy splash, safe-area aware layout, and `www/offline.html`
  when the site cannot load.

## Build

```sh
cd apps/sweep/mobile
npm install
npm run android:prepare        # cap add/sync android + icons, splash, version, signing
cd android && ./gradlew assembleRelease
npm run ios:prepare            # macOS + Xcode: cap add/sync ios + icons, splash, version
```

Icons and splash images in `resources/` (and the web PNG icons) are generated by
`python scripts/make-icons.py` from the same geometry as `web/icons/app-icon.svg`.

### Signing (Android updates must always use the same key)

Release signing reads `SWEEP_ANDROID_KEYSTORE_PATH`, `SWEEP_ANDROID_SIGNING_PASSWORD` and
`SWEEP_ANDROID_KEY_ALIAS` (PKCS#12). In CI the *Sweep apps* workflow uses the repository secrets
`SWEEP_ANDROID_KEYSTORE_BASE64` / `SWEEP_ANDROID_SIGNING_PASSWORD` when present, and otherwise the developer
key Mint is already signed with (`MINT_ANDROID_*`, alias `mint`). `android-certificate-sha256.txt` pins that
key's certificate: CI refuses to publish an APK signed with anything else, because Android would refuse to
install it over an existing Sweep. If you ever switch to a dedicated Sweep key, do it before the first public
install and update the fingerprint file in the same commit.

## Distribution

- **Android:** <https://github.com/juw12/projects/releases/download/sweep/Sweep-Android.apk>, rebuilt and
  emulator-tested by CI whenever this folder changes.
- **iPhone:** Safari → Share → *Add to Home Screen* on <https://juw12.github.io/projects/sweep/app.html>
  (free, full screen, always current). CI also builds a simulator-tested `Sweep-iPhone-unsigned.ipa` for
  sideloading (AltStore / Sideloadly). The App Store or TestFlight needs an Apple Developer account
  (US$99/year), a signing certificate and provisioning profile in the repository secrets.
