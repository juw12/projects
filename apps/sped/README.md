# Sped is now Hazel Sped

Sped joined Shortcraft and the original Hazel in one app, **Hazel**. Its source now lives in
[apps/hazel](../hazel/) — web app in [apps/hazel/web/sped](../hazel/web/sped/), docs and tools in
[apps/hazel/sped](../hazel/sped/).

- App: https://juw12.github.io/projects/hazel/sped/
- Web: https://juw12.github.io/projects/hazel/sped/web.html
- Mobile: https://juw12.github.io/projects/hazel/sped/mobile.html

Old website addresses redirect automatically, saved looks keep loading, and Sped/Hookline recipe files still load.
The old offline worker at `/projects/sped/` is retired and clears only Sped's own `sped-v…` caches.
