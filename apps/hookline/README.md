# Hookline is now Hazel Sped

Hookline was renamed Sped, and Sped is now **Hazel Sped**, one of the three apps in [Hazel](../hazel/).
The current source is in [apps/hazel/web/sped](../hazel/web/sped/) (docs and tools: [apps/hazel/sped](../hazel/sped/)).

- App: https://juw12.github.io/projects/hazel/sped/
- Web: https://juw12.github.io/projects/hazel/sped/web.html
- Mobile: https://juw12.github.io/projects/hazel/sped/mobile.html

Old website addresses redirect automatically. Hookline recipe files still load in Hazel Sped.
The old offline worker at `/projects/hookline/` is retired and clears only Hookline's own caches.
