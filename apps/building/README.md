# Building

This is the brainstorming / work-in-progress section. Apps here are concepts, drafts, or things being figured out — **not** committed launches.

Each project in this folder should be:
- An idea worth exploring
- Not ready for the main `apps/` section
- Tracked so we don't lose context between sessions

## How this differs from `apps/`

| | `apps/building/` | `apps/` |
|---|---|---|
| Status | WIP / brainstorming | Shipped / production |
| Public? | No | Yes (live site) |
| Quality bar | "Idea worth keeping" | "Production-ready" |
| Promotion path | When ready → moves to `apps/` | Stays here |
