# Section 02: Product Descriptions That Convert (20 prompts)

Etsy descriptions aren’t Amazon bullet points. They build trust, handle objections, and quietly stuff long-tail keywords without sounding like a robot. These prompts give you a 5-section framework: Hook → Story → Specs → Care → CTA.

---

### P02-001 — Full Description From Scratch (5-Section Framework)
**Use when:** You have a new product and need a complete description today.
```
Product: [PASTE short description or photo details]
Target buyer: [e.g., new mom, remote worker, gift buyer]
Price: $[X]

Write an Etsy description in this exact 5-section structure:

1. **Hook (1-2 sentences):** The first line a buyer reads in search results preview. Make it emotional, not generic. Lead with the benefit or feeling, not the product specs.

2. **The Story (1 paragraph, 4-6 sentences):** Why this product exists. Who makes it. What problem it solves. Make me care.

3. **What's Included / Specs (bulleted list):**
   - Materials
   - Dimensions
   - Color options
   - Personalization details (if any)
   - Processing / shipping time
   - Where it's made

4. **Care Instructions (3-5 bullets):** Specific, actionable, in the buyer's language.

5. **Soft CTA (1-2 sentences):** Invite them to message you with questions. Don't hard-sell.

Naturally include these keywords throughout (don't force): [list 5-8 keywords]
Length: 250-400 words total.
```

### P02-002 — Rewrite a Flat / Boring Description
**Use when:** You have a description but it reads like a spec sheet.
```
Current description:
"[PASTE]"

Rewrite it so it:
- Opens with an emotional hook (not "This beautiful handcrafted...")
- Sounds like a human wrote it, not a template
- Includes the same specs but as part of the story
- Adds 1-2 trust signals (warranty, returns, materials, etc.)
- Ends with a soft CTA

Keep length similar (within 50 words of original) unless the original was under 150 words.
```

### P02-003 — Description for a Personalized / Custom Product
**Use when:** Buyers need to know exactly what to type in the personalization box.
```
Product: [PASTE]
What buyer customizes: [e.g., name, date, 2 lines of text, photo, color choice]

Write a description with a dedicated section called "How to Personalize" that:
- Tells the buyer EXACTLY what to type in the personalization field
- Shows character / word limits
- Gives 3 example personalization inputs (so they can copy the format)
- Warns about emojis / special characters (if applicable)

Rest of description follows the standard 5-section framework.
```

### P02-004 — Description That Handles the "Why Is It So Expensive?" Objection
**Use when:** Your price is higher than mass-produced alternatives.
```
Product: [PASTE]
Price: $[X]
Common mass-produced alternative price: $[Y cheaper]

Write a description section (3-5 sentences) that justifies the price WITHOUT apologizing. Address:
- Material quality / why your material beats the alternative
- Time / craftsmanship (be specific — hours, not "lots of love")
- What breaks / fails in the cheap version
- Lifetime / warranty / repair policy

Tone: confident, not defensive. Don't trash the competitor.
```

### P02-005 — Description for a Digital Product on Etsy
**Use when:** Selling printables, SVGs, templates, prompt packs, etc.
```
Digital product: [PASTE]
What's delivered: [e.g., 5 PDF files, 1 ZIP, instant download]
What buyer can do with it: [e.g., print at home, edit in Canva, use commercially up to 50 times]

Write a description with these sections:
1. What you get (bullet list of file types + sizes + quantities)
2. How to use it (2-3 steps)
3. License terms (plain English, not legalese)
4. Refund policy (Etsy digital products are non-refundable — say so kindly)
5. Need help? (CTA to message)

Add 1-2 keyword phrases naturally. Keep total under 250 words — digital buyers skim.
```

### P02-006 — Description That Reads as Gift-Ready
**Use when:** Your product is bought primarily as a gift.
```
Product: [PASTE]
Gift occasions you fit: [e.g., wedding, birthday, Mother's Day, retirement, housewarming]

Write a description section that:
- Positions the product as "the kind of gift that gets remembered"
- Names 3 specific occasions with one tailored sentence each
- Mentions gift wrapping / ready-to-give packaging if you offer it
- Closes with a phrase that solves the buyer's "will they love it?" anxiety

Length: 150-200 words. Tone: warm, not salesy.
```

### P02-007 — Description for a Product You Make in Batches
**Use when:** You want to mention scale (e.g., "made in small batches") without sounding mass-produced.
```
Product: [PASTE]
How it's made: [e.g., "I make 20 of these per week in my home studio", "Made to order, 3-day turnaround", "Limited run of 50"]

Write 3 versions of an "About the Maker / Process" paragraph that:
- Communicates care and craft
- Acknowledges production reality without killing the "handmade" feel
- Each version uses a different angle: scarcity, quality control, customer touchpoint

Then recommend which version fits my brand voice: [e.g., cozy artisan, modern minimalist, luxury, playful].
```

### P02-008 — Description for a Product With Confusing Sizing / Fit
**Use when:** You get DMs like "what size should I get?"
```
Product: [PASTE with sizing detail]
Sizing confusion source: [e.g., "runs small", "Asian sizing", "fits two ways", "choose from 5 sizes"]

Write a "Sizing & Fit" section that:
- Opens with one sentence telling the buyer exactly which size to pick (decision shortcut)
- Includes a sizing chart as plain text (so it shows up in search snippet)
- Gives 2 examples: "If you're 5'4" and 130 lbs, choose Medium"
- Addresses the #1 most-asked sizing question

End with: "Still unsure? Message me — I'll pick the right size for you."
```

### P02-009 — Description for a Niche Buyer You're Trying to Reach
**Use when:** Your listing gets traffic but wrong buyers.
```
Product: [PASTE]
Current buyer who finds me (wrong fit): [describe]
Target buyer (right fit): [describe]

Rewrite the hook (first 1-2 sentences) so the RIGHT buyer self-selects in and the wrong buyer bounces. Then rewrite the Story section to use the target buyer's language, references, and pain points.

Keep the Specs and Care sections identical — those don't change.
```

### P02-010 — Description for a Product Where Buyers Hesitate on Materials
**Use when:** You get questions like "is this hypoallergenic?" "is this food-safe?" "will this rust?"
```
Product: [PASTE]
Material: [e.g., stainless steel, polymer clay, sterling silver, soy wax, MDF]
Common hesitation: [paste the most-asked question]

Write a "Materials & Safety" section that:
- Names the material clearly (no vague "eco-friendly" claims)
- Cites a relevant safety standard if applicable (FDA, CPSIA, ASTM, etc.)
- Addresses the specific hesitation head-on
- Closes with a sentence that turns the material into a feature, not a worry

Length: 80-120 words. Plain English.
```

### P02-011 — Description That Works in Search Preview (First 160 Characters)
**Use when:** Etsy shows only the first ~160 characters of your description in search results.
```
Full description I have:
"[PASTE]"

Rewrite ONLY the first 160 characters (the snippet buyers see in search results) so it:
- Includes the primary keyword naturally
- Has a hook or benefit
- Doesn't end mid-sentence (Etsy cuts off awkwardly)
- Makes the buyer click "see more"

Then suggest the next 40 characters (so I know what's visible just past the cutoff) and what to put there.
```

### P02-012 — Description That Builds Trust Without Social Proof You Don't Have
**Use when:** You're new and don't have reviews yet.
```
Product: [PASTE]

Write a "Why Buy From Me" section (NOT a generic "About" page) that uses these trust-builders instead of reviews:
- Process transparency ("I send a photo before shipping")
- Material specificity (not "high quality", but "100% cotton, OEKO-TEX certified")
- Realistic shipping promise ("made to order in 3 days")
- Personal touch ("I read every message myself")

Length: 100-150 words. Tone: humble-confident.
```

---

### P02-013 — Description for a Product With Multiple Variants
**Use when:** You sell 10 colors / 5 sizes / 3 materials under one listing.
```
Product variants: [e.g., 12 colors, 4 sizes, 3 metals]
Listing title: [PASTE]

Write a description that:
- Names the variants upfront so the buyer doesn't bounce thinking "this isn't for me"
- Lists variants clearly (bullet or table)
- Asks the buyer to specify their choice in personalization / note to seller (if applicable)
- Includes a sentence per variant family on who it's for

Don't list every SKU. Group sensibly.
```

### P02-014 — Description for Wholesale / Bulk Buyers
**Use when:** You want B2B or wedding-pro clients to find and trust your listing.
```
Product: [PASTE]
Minimum order: [e.g., 12 units, 50 units, no minimum]
Bulk discount: [e.g., 10% off 10+, 20% off 50+]

Write a "Wholesale & Bulk Orders" section that:
- States the minimum clearly
- Lists volume discount tiers
- Mentions lead time for large orders (real, not aspirational)
- Invites a message for custom bulk quotes

Length: 100-150 words. Tone: professional, not consumer-y.
```

### P02-015 — Description That Solves "Why Etsy vs. Amazon?"
**Use when:** You sell something Amazon sells cheaper.
```
Product: [PASTE]
Amazon equivalent: [describe the cheaper version]
What makes mine different: [e.g., "I make these in my studio", "Each one is slightly different", "Made to order"]

Write a 100-150 word paragraph that names the difference WITHOUT trashing Amazon. Buyers on Etsy already want to buy on Etsy — just remind them why.

Don't use the phrase "Amazon doesn't..." — keep it positive.
```

### P02-016 — Description for a Product That's Also a "Treat Yourself" Item
**Use when:** Most of your buyers are self-purchasers, not gift-givers.
```
Product: [PASTE]

Write a "Treat Yourself" paragraph (3-4 sentences) that:
- Validates the impulse to buy for oneself
- Names the small everyday moment this product upgrades (morning coffee, desk setup, evening wind-down)
- Doesn't guilt the buyer or push scarcity
- Ends with a soft "you deserve it" without being cringey

Tone: warm, slightly playful. Avoid "luxury" if your price doesn't match.
```

### P02-017 — Description for a Product Where You're the Artist / Maker
**Use when:** The maker's story is the differentiator (e.g., printmaker, ceramicist, woodworker).
```
About me (1-2 sentences): [PASTE brief bio or location]
Product: [PASTE]
How it relates to my story: [e.g., "I started making these after..." / "I make these in my garage studio in Portland"]

Write a "Meet the Maker" section that:
- Tells a 2-3 sentence origin story (real, not inspirational-poster)
- Connects the maker's background to the product (not a non-sequitur)
- Names location if it's a story element
- Closes with one sentence that makes the buyer feel like supporting a small business

Length: 80-120 words. Tone: human, not corporate.
```

**Use when:** Your DMs are flooded with the same questions.
```
Product: [PASTE]
Top 5 questions I get in DMs:
1. [question]
2. [question]
3. [question]
4. [question]
5. [question]

Write a "Quick Answers" section (FAQ format) that addresses all 5 questions in 1-2 sentences each. Pre-empt the buyer's hesitation so they don't bounce to a competitor.

Add a final line: "Anything else? I read every message and reply within [X hours]."
```

### P02-019 — Description for a Product in a Trendy / Fast-Moving Niche
**Use when:** Your category is currently hot (Taylor Swift merch, coastal grandmother, quiet luxury).
```
Trend I'm riding: [e.g., "coastal grandmother aesthetic", "mob wife aesthetic", "dark academia"]
Product: [PASTE]
Trend end date estimate: [e.g., "12-18 months", "this season only"]

Write a description that:
- References the trend in the first 2 lines (so trend-searchers find it)
- Doesn't date the listing to the trend (so it still works in 2 years)
- Uses trend language buyers actually search ("coastal grandma kitchen", "mob wife jewelry")
- Positions the product as a "wearable version of the aesthetic"

Length: 200-280 words. Avoid forcing the trend if it doesn't fit the product — buyers can smell it.
```

### P02-020 — Description That Asks for the Review (Without Begging)
**Use when:** You want to prompt a 5-star review subtly at the end of the description.
```
Product: [PASTE]
Stage of buyer journey this targets: post-purchase (they're reading the description because they already bought, or are about to)

Write a final 2-3 sentence paragraph that:
- Thanks the buyer for considering a small business
- Plants the seed that you'd love to hear how the product works for them
- Invites them to message you with any issue FIRST (so they come to you before leaving a 1-star review)
- Doesn't say "please leave 5 stars" — that's against Etsy's TOS

Tone: grateful, not needy.
```
