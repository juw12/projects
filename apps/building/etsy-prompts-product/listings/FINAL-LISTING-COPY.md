### The five differentiators, and what's missing

1. **Brand voice system (research Gap 3, "single highest-leverage innovation") = Phase 1 = MISSING.** No file contains a "Brand Voice Extraction" prompt. This is your #1 structural differentiator and it does not exist yet. Build it: one prompt that asks 5 questions and outputs a "voice block."
2. **Diagnosis prompts (research Gap 4, "highest-intent search") = Phase 6 = MISSING.** No "my listing gets 200 views but 0 sales" prompt anywhere. Build 15.
3. **2026 algorithm + AI compliance (research Gap 5) = MISSING across all files.** Nothing addresses the Oct 2026 AI policy (AI disclosure, the one-unedited-photo rule, no bot-generated listings), LLM-based search, or "write for the ChatGPT shopping agent." This is your most timely differentiator and it is absent. Build a short section (~10 prompts).
4. **Show real output (research Gap 1) = not done in any file.** None of the 70 prompts include an example output. This is a presentation gap across all four files. Add a real output screenshot/transcript to at least 10 key prompts (the tag generator and title builder first).
5. **Workflow, not collection (research Gap 6) = not applied.** The 70 prompts are grouped by type, not run as a sequence. Add a one-page "quick start: run these in this order" so the product reads as a system, which is also what your listing copy promises.

### Specific weak spots in the existing files (cite + fix, no full rewrite)

- **`prompts/01-titles.md`, line 3 (intro):** says Etsy's ranking is "'Etsy Search' or 'Marmalead-style'." Marmalead is a third-party tool, not Etsy's ranking system. This is a factual sloppiness that could be in the PDF a buyer reads. Fix the one sentence to describe Etsy's actual signal (front-loaded title keywords + tags + attributes + customer experience).
- **All four files: no "voice block" wiring.** The title and description prompts say "sounds like a human" but never tell the user to paste in their brand voice block. Once you build Phase 1, add a `[PASTE your brand voice block]` line to the flagship prompts (at least `P01-001`, `P02-001`, `P02-002`). Without this, the "sounds like you" promise in the listing copy is not actually delivered by the prompts.
- **`prompts/03-tags-seo.md` is your strongest file.** `P03-001` already bakes in the 20-char / 13-tag / no-repeat constraints (research Gap 2). Keep it as the hero. `P03-015` asks for 52 tags in one prompt (4 sets of 13); that is a lot for one ChatGPT call, consider splitting it into per-quarter prompts so output quality holds.
- **`prompts/04-customer-service.md` is strong but skews physical-goods.** Sizing, shipping, and damaged-item prompts are less relevant to the many digital-product sellers in your audience. That is fine for a general pack, but do not over-sell the customer-service section to digital sellers in your copy.
- **Delivery scaffolding exists but is unverified.** The project root has `build_pdf.py` and `build_product.py`, and a `product-files/` folder. I did not read or run these. Confirm they actually produce the PDF + Notion + Google Docs bundle your listing promises (research Gap 7) before you say "Notion included."
