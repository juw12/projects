## The 6-Phase Etsy Listing Workflow

Follow this sequence every time you list a new product. Total time: ~5 minutes once you've run it a few times.

---

### Phase 1: Validate (Before You Make the Product)

**Time:** 5-10 minutes
**Prompts to use:** Section 08 (P08-001, P08-014, P08-015)

Before you make anything, run the validation prompt. Is this product worth building? What's the demand signal? Will it make money?

**Why this phase matters:** Most Etsy sellers make products first, then try to find buyers. Flip it. Validate demand, then build what buyers already want.

**Output:** A "Build / Pivot / Skip" verdict with 3 reasons.

---

### Phase 2: Research & Lock Your Voice

**Time:** 3 minutes
**Prompts to use:** Section 08 (P08-002, P08-004) — once

Run these two prompts ONCE for your shop:

- **Competitor deep-dive (P08-004):** Pick your top 3 competitors. Run the prompt. Save the output as your "competitor playbook."
- **Brand voice lock (manual):** Answer this for yourself: "My shop sounds like..." (e.g., "a calm friend who's good at [X]"). Paste it into a "voice reference" doc.

**Why this phase matters:** Every prompt that generates copy for you will sound generic unless you've defined your voice. Do this once, reuse forever.

**Output:** A voice reference doc. Reuse it by pasting it into every prompt's [brackets].

---

### Phase 3: Write the Listing (The Core 5 Minutes)

**Time:** 5 minutes
**Prompts to use:** Section 01 (titles), Section 02 (descriptions), Section 03 (tags)

Run these in sequence:

1. **P01-001 → P01-003:** Generate 3-5 title options. Pick the best, paste back into the prompt for refinement.
2. **P02-001:** Generate the full 5-section description. Paste your voice reference + brand info into the brackets.
3. **P03-001 + P03-003:** Generate 13 tags. Then generate 13 long-tail variants. Pick the 13 strongest.

**Why this phase matters:** This is the actual listing. Do it in one focused session — don't spread it across days. The momentum of running prompts 1, 2, 3 back-to-back is what makes this fast.

**Output:** A complete draft listing ready for photos.

---

### Phase 4: Photos

**Time:** 30-90 minutes (the longest phase)
**Prompts to use:** Section 07 (P07-001, P07-002, P07-010)

Before you shoot, run the shot list and lifestyle scene prompts. You'll walk into the shoot with a plan instead of improvising 10 angles.

**Why this phase matters:** Photos are the #1 conversion lever. A perfect listing with bad photos won't sell. A mediocre listing with great photos will.

**Output:** 10 product photos + alt-text for each.

---

### Phase 5: Launch & Distribute

**Time:** 15 minutes
**Prompts to use:** Section 05 (P05-002 for Pinterest, P05-001 for Instagram)

After the listing goes live:

- **Pinterest:** Run P05-002 to generate a pin description. Create 3-5 pin variations.
- **Instagram:** Run P05-001 to write a product showcase caption.
- **Optional:** Run P05-003 to script a 15-30 second Reel/TikTok.

**Why this phase matters:** Etsy traffic is half Etsy search, half external (Pinterest, Instagram, TikTok). Don't just list — push.

**Output:** 1 Pinterest pin + 1 IG post + (optional) 1 Reel script.

---

### Phase 6: Diagnose & Iterate (Weekly, 10 Minutes)

**Time:** 10 minutes per week
**Prompts to use:** Section 09 (P09-001, P09-013, P09-014)

Every week, look at Etsy Stats. Find your worst-performing listing. Run the diagnosis prompt. Fix the ONE thing the prompt tells you to fix.

**Why this phase matters:** Etsy sellers who grow treat their shop like a portfolio — iterate weekly. Sellers who stall post and pray.

**Output:** A weekly improvement action. Do it. Repeat next week.

## How to Use Each Prompt

Every prompt in this pack follows the same format:

1. **Prompt ID (e.g., P01-001)** — find it fast.
2. **"Use when" line** — tells you when to reach for it.
3. **Copy-paste block** — the actual prompt text.
4. **[BRACKETS]** — fill these in for your product. Replace each `[bracket]` with your specific info.
5. **Bullets inside the prompt** — these are constraints. ChatGPT will follow them. Don't delete them.

**Pro tips:**

- Run prompts in ChatGPT (free tier works), Claude, or any LLM.
- For best results, paste your "voice reference" doc into EVERY prompt that generates copy. This keeps your voice consistent.
- If the first output is bad, run it again with "Make it [X] more" or "Try again, but [Y]."
- Don't paste the whole pack into ChatGPT. Use one prompt at a time.

# Section 01 — Listing Titles That Rank (15 prompts)


Etsy titles max out at 140 characters. Etsy’s search engine (called “Etsy Search” or “Marmalead-style” ranking) weights the first few words the heaviest, then scans for keywords across the rest. These prompts force ChatGPT to write titles that earn clicks AND rank.

---

### P01-001 — Long-Tail Keyword Title Builder
**Use when:** You have a product and need a title that hits the exact phrase buyers search.
```
You are an Etsy SEO specialist. Write 5 listing titles for my product.

Product: [PASTE your product description or photo description]
Target buyer: [e.g., new mom, remote worker, dog owner, teacher]
Top 3 keywords I want to rank for: [keyword 1, keyword 2, keyword 3]

Constraints:
- 140 characters max each (count and report)
- Front-load the strongest keyword in the first 40 characters
- Use natural phrasing a human would type, not keyword stuffing
- Include one long-tail phrase (3+ words) per title
- End with a benefit or occasion word (gift, wedding, personalized, custom)

Return titles as a numbered list with character count for each.
```

---

### P01-002 — Title Rewrite From a Competitor’s Top-Seller
**Use when:** You see a competitor ranking well and want to write a similar-but-better title.
```
Here’s the title of a top-ranking Etsy listing:
"[PASTE competitor title here]"

My product is similar but differs in: [e.g., material, color, size, personalization, price point].

Write 5 alternative titles that:
- Target the same primary keyword but use different secondary keywords
- Highlight my differentiator in the first 60 characters
- Avoid copying the exact phrase structure (no plagiarism risk)
- Stay under 140 characters

For each, briefly note which competitor title it’s differentiated from.
```

---

### P01-003 — Seasonal / Occasion Title Generator
**Use when:** Q4, Valentine’s, Mother’s Day, weddings, Christmas, back-to-school, etc.
```

Write 5 titles that:
- Include the occasion keyword (e.g., "gift for teacher", "stocking stuffer")
- Still rank for evergreen search terms (so the listing sells year-round too)
- Use seasonal phrasing buyers actually search: "Christmas gift", "holiday hostess", "Secret Santa"
- Under 140 characters

After the titles, list 3 tags I should pair with each title to capture both seasonal and evergreen traffic.
```

---

```
This lets me A/B test which use case converts best in my niche.
```

### P01-005 — Title That Beats Etsy's "Stuffing" Penalty
**Use when:** You’re tempted to repeat keywords and need a clean, natural title.
```

Etsy’s algorithm de-duplicates and penalizes keyword stuffing. Rewrite it so:
- Each major word appears only once unless grammatically required
- The same idea isn't repeated in different words (no "handmade - hand crafted - artisan")
- The flow still sounds like a real human describing the item
- Strongest keyword stays in the first 40 characters
- 140 characters max

Return 3 versions: minimal, balanced, and keyword-rich (in case my niche rewards density).
```

---

# Section 02 — Descriptions That Convert (20 prompts)


Etsy descriptions aren’t Amazon bullet points. They build trust, handle objections, and quietly stuff long-tail keywords without sounding like a robot. These prompts give you a 5-section framework: Hook → Story → Specs → Care → CTA.

---

### P02-001 — Full Description From Scratch (5-Section Framework)
**Use when:** You have a new product and need a complete description today.
```
Product: [PASTE short description or photo details]
Target buyer: [e.g., new mom, remote worker, gift buyer]
Price: $[X]

Write an Etsy description in this exact 5-section structure:

1. **Hook (1-2 sentences):** The first line a buyer reads in search results preview. Make it emotional, not generic. Lead with the benefit or feeling, not the product specs.

2. **The Story (1 paragraph, 4-6 sentences):** Why this product exists. Who makes it. What problem it solves. Make me care.

3. **What's Included / Specs (bulleted list):**
   - Materials
   - Dimensions
   - Color options
   - Personalization details (if any)
   - Processing / shipping time
   - Where it's made

4. **Care Instructions (3-5 bullets):** Specific, actionable, in the buyer's language.

5. **Soft CTA (1-2 sentences):** Invite them to message you with questions. Don't hard-sell.

Naturally include these keywords throughout (don't force): [list 5-8 keywords]
Length: 250-400 words total.
```

---

### P02-002 — Rewrite a Flat / Boring Description
**Use when:** You have a description but it reads like a spec sheet.
```
Current description:
"[PASTE]"

Rewrite it so it:
- Opens with an emotional hook (not "This beautiful handcrafted...")
- Sounds like a human wrote it, not a template
- Includes the same specs but as part of the story
- Adds 1-2 trust signals (warranty, returns, materials, etc.)
- Ends with a soft CTA

Keep length similar (within 50 words of original) unless the original was under 150 words.
```

# Section 03 — Tags & Etsy SEO (15 prompts)


Etsy gives you 13 tags per listing, each max 20 characters. Tags + title are the only direct SEO inputs Etsy actually listens to (descriptions barely count anymore). These prompts generate tags that surface for real buyer searches — not vanity keywords.

---

### P03-001 — Generate the 13 Tags From Scratch
**Use when:** You have a product but no clue which tags to use.
```
Product: [PASTE description or photo details]

Generate 13 Etsy tags that:
- Each is 20 characters max (count and report)
- Are multi-word phrases buyers actually search (not single keywords like "gift")
- Cover the 4 tag types Etsy rewards: product type, audience, occasion, style/material
- Don't repeat words across tags (Etsy de-duplicates)
- No commas, no all-caps, no fluff

Format as a numbered list with character count.
After the list, mark each tag with its category:
[P] = product type
[A] = audience
[O] = occasion
[S] = style / material
```

---

**Use when:** You see a competitor ranking on page 1 and want their tags.

```
- The listing title
- The first 160 characters of the description (which often leak tag phrases)
- The categories they chose
- The buyer language in their reviews

Generate 13 tags this competitor is MOST LIKELY using. Then write 5 DIFFERENT tags I can use to out-rank them by targeting the gap (a related search they didn't cover).

Format both lists with character counts.
```

---

### P03-003 — Long-Tail Tag Generator (Low Competition Wins)
**Use when:** You want to rank on page 1 for specific 3-4 word phrases.
```
Product: [PASTE]

- Include the core keyword
- Add a buyer-specific or occasion-specific modifier
- Are phrases a human would actually type ("personalized cutting board wedding gift", not "personalized cutting board personalized gifts custom custom custom")
- Each tag 20 characters max

Long-tail tags convert better because the buyer searching them knows what they want.

Estimate competitiveness for each (Low / Medium / High) based on how specific the phrase is.
```

### P03-004 — Multi-Word vs Single-Word Tag Strategy

```
- Closes warmly without over-promising
```

# Section 08 — Product Research & Validation (15 prompts)


Most Etsy sellers build what they LIKE, then wonder why it doesn't sell. These prompts force the discipline of validating demand BEFORE you spend 3 weeks making a product nobody wants. They also cover how to spot trends early and decide what to make next.

### P08-001 — Validate a Product Idea Before You Make It
**Use when:** You have an idea and want to know if it's worth the time.
```

2. **Competitor count:** How many similar listings exist on Etsy? (Roughly — top 50 results in the category.)

3. **Competitor revenue signal:** Do the top 5 competitors have 100+ favorites / sales? Yes = proven demand.

4. **Review mining:** What are buyers saying in competitor reviews? Specifically, what's the #1 thing they wish was different?
```

# Section 09 — Troubleshooting, Diagnosis & Strategy (15 prompts)


The prompts nobody else ships. Most prompt packs give you templates for the happy path. These handle the moments every Etsy seller actually lives through: the listing that gets traffic but no sales, the title that ranks but doesn't convert, the customer who's furious, the shop that's been quiet for months. This is the section that turns a list of prompts into a system.

---

### P09-001 — Diagnose a Listing That's Getting Traffic but No Sales
**Use when:** "My listing has 200 views and 0 orders." This is the #1 Etsy seller complaint.
```
Listing details:
- Title: [PASTE]
- Tags: [PASTE 13 tags]
- First photo: [describe]
- Price: $[X]
- Visits in the last 30 days: [X]
- Orders in the last 30 days: 0

Diagnose, in order of likelihood, what's killing the conversion:

1. **Click-through problem (right buyer, wrong hook):** First photo doesn't match the search intent. Suggest 3 specific photo changes.

2. **Price problem:** Listing is being shopped but the price is the barrier. Suggest whether to test lower price, add value (bundle), or reframe the value (description fix).

3. **Objection problem:** Buyer has a question that the listing doesn't answer. Identify the #1 unasked question.

4. **Trust problem:** Listing lacks social proof / details / professionalism. Identify the weakest trust signal.

5. **Title mismatch:** Buyers are clicking but the product isn't what they expected. Rewrite the title to better match the photo + description.

End with: my single highest-leverage fix this week.
```

---

### P09-002 — Diagnose a Listing That's Ranked but Buried (Page 5+)
**Use when:** You know your listing exists for a search but it's invisible because it ranks page 5+.
```

- Category: [PASTE]

- Current search rank estimate for [target keyword]: [page 3-5 / page 5+ / unknown]

Etsy's ranking factors (2026):
- Title relevance + click-through rate
- Tag relevance + listing quality score
- Conversion rate history
- Customer experience signals (reviews, message response rate)
```
