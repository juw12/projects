# Canva Cover Image — Step-by-Step Walkthrough

If you've never designed in Canva before, follow this literally. Every click is spelled out. 30 minutes, no design skill needed.

---

## Step 0: Setup (5 min, one-time)

1. Open your browser, go to **canva.com**
2. Click **Sign up** (top right) — use your Google account, takes 30 seconds
3. Once logged in, you'll see the dashboard. Don't click anything yet.

---

## Step 1: Create the Gumroad Cover (16:9, 1280×720 px)

### 1a. Start a new design

1. Click the purple **"Create a design"** button (top right)
2. Click **"Custom size"** (bottom right of the popup)
3. Type **1280** in the width box, **720** in the height box
4. Click **"Create new design"**

You'll see a blank canvas.

### 1b. Set the background color

1. Click anywhere on the empty background (not on any text/element yet)
2. The color picker toolbar appears at the top. Click the small colored square.
3. In the hex code field (top of the color picker), type **#F8F4EE** and press Enter
4. Your background is now warm cream paper.

### 1c. Add the left color block (terracotta accent)

1. In the left sidebar, click **"Elements"** (the 4-square icon)
2. Search for **"rectangle"** in the elements search bar
3. Drag any rectangle onto the canvas
4. Resize it: drag the right edge so it covers the left 1/3 of the canvas (roughly 425 pixels wide × full height)
5. Click the rectangle, then change its color:
   - Click the color square in the top toolbar
   - Type **#C76E4A** in the hex field, press Enter
6. Position: drag so the left edge is at the canvas edge, top/bottom flush

### 1d. Add the headline text

1. In the left sidebar, click **"Text"**
2. Click **"Add a heading"**
3. Type: `150 ChatGPT Prompts.`
4. Click the text to select it. Now in the top toolbar:
   - **Font:** Click the font name → search for **"Playfair Display"** → select it
   - **Size:** Type **72** in the size field
   - **Color:** Click the color square → type **#1F1A17** → Enter
5. Position: drag this text into the left 1/3 (on the terracotta block)
   - If you can't see it well on terracotta, change color to **#FFFFFF** instead

### 1e. Add the subhead text

1. Add another text element (**Text → Add a subheading**)
2. Type: `The System.`
3. Font: **Playfair Display**, Size **48**, Color **#1F1A17** (or white)
4. Position: below the first headline

### 1f. Add the small caps line

1. Add another text element (**Text → Add a little bit of body text**)
2. Type: `FOR ETSY SELLERS WHO WANT TO SHIP LISTINGS, NOT STARE AT THEM.`
3. Font: search for **"Inter"** → select the **Bold** weight
4. Size: **14**, Color **#1F1A17**
5. Position: above the headline

### 1g. Add the product preview area (right 2/3)

This is the hardest part. You have 3 options — pick one:

**Option A (Easy — 5 min):** Skip the visual. Just add a placeholder.
1. Add a rectangle (Elements → search "rectangle")
2. Resize to fill the right 2/3
3. Color: light gray **#E8E2D8**
4. Add text on top: `[Product preview image goes here]`
5. Replace with a real product screenshot later

**Option B (Medium — 15 min):** Use a free Canva template.
1. In the left sidebar, click **"Templates"**
2. Search for **"ebook mockup"** or **"product cards"**
3. Find a clean template with stacked cards or fanned layout
4. Click **"Customize this template"**
5. Replace the text on the cards with section names:
   - "01 / Listing Titles That Rank"
   - "02 / Descriptions That Convert"
   - "03 / Tags & Etsy SEO"
   - "04 / Customer Service Replies"
   - "07 / Mockups & Photography"
   - "09 / Troubleshooting & Diagnosis"
6. Crop/position the template to fit your right 2/3 area

**Option C (Best — 20 min):** Make the cards yourself.
1. Add 6 small rectangles (each ~150×220 px)
2. Each card color: white **#FFFFFF**, with a thin terracotta border (color picker → choose terracotta → set border thickness to 1px)
3. Rotate each card slightly (top toolbar has a rotate slider) — fan them out at 0°, 5°, 10°, -5°, -10°, 0°
4. Add small text on each card with the section names
5. This looks like a real "stack of prompt cards" product photo

### 1h. Add the badge

1. Add text (**Text → Add a little bit of body text**)
2. Type: `PDF + Notion Template`
3. Font: **Inter Bold**, Size **16**, Color **#1F1A17**
4. Position: bottom-right corner

### 1i. Save

1. Top right → **"Share"** → **"Download"**
2. File type: **PNG** (sharper than JPG)
3. Click **"Download"**

Save as: `cover-gumroad.png`

## Step 2: Create the Etsy Thumbnail (Square 1:1, 2000×2000 px)

1. **Create a design** → **Custom size** → **2000 × 2000**
2. **Background:** Top section (top 1/3) — color **#C76E4A** (terracotta)
   - To do this: add a rectangle covering top 1/3, set color to terracotta
   - OR click on the canvas background, color picker → terracotta, then resize canvas (no, can't resize bg)
   - Easier: add a rectangle covering top 1/3, color terracotta. Repeat for middle and bottom.
3. **Top 1/3 — Big text:**
   - Text → Heading → `150 ChatGPT PROMPTS`
   - Font: Playfair Display Bold, Size 120 (it's a big canvas)
   - Color: white **#FFFFFF**
   - Center it horizontally, position in the terracotta top block
4. **Top 1/3 — Subtext:**
   - Text → Subheading → `for Etsy Sellers`
   - Font: Inter Regular, Size 60, Color white
   - Below the big text
5. **Middle 1/3 — Product preview:**
   - Same approach as the Gumroad cover (Option B from Step 1g — use a Canva template)
   - OR just use a plain cream background **#F8F4EE** for the middle
6. **Bottom 1/3 — CTA text:**
   - Background rectangle: terracotta **#C76E4A**
   - Text: `WRITING SYSTEM • PDF + NOTION`
   - Font: Inter Bold, Size 60, Color white
   - Center it

7. **Download as PNG.** Save as `thumbnail-etsy.png`

## Step 4: Optional Polish (10 min)

### Add subtle shadows to the cards

1. Click on a card rectangle
2. Top toolbar → click **"Effects"** (the 4-circle icon)
3. Choose **"Shadow"**
4. Set: blur 8, offset Y 4, opacity 30%

### Add a subtle texture to the background

1. Click the background
2. Search "Elements" → "linen texture" or "paper texture"
3. Drag the texture over the background
4. Top toolbar → adjust opacity to 15-20%

---

## Step 5: Final Checklist Before Using

- [ ] Cover image looks good at small size (open it on your phone and zoom out)
- [ ] Text is readable when the image is shrunk to ~300px wide (this is how it'll appear in Etsy search)
- [ ] No spelling errors (proofread every word)
- [ ] Files saved as PNG, not JPG
- [ ] File names match what you need for each platform:
  - Gumroad cover → `cover-gumroad.png`
  - Etsy thumbnail → `thumbnail-etsy.png`
  - Pinterest pins → `pin-1.png`, `pin-2.png`, etc.

---

## Common Mistakes (Don't Do These)

- **Don't use a Canva template as-is.** Templates look like everyone else's Etsy shop. Customize the colors to match the warm palette above.
- **Don't add stock photos of women with laptops.** It's the #1 Etsy listing cliche. Use the card-stack visual instead.
- **Don't put too much text on the thumbnail.** Etsy search shows thumbnails at 200-300 px wide. Less is more.
- **Don't forget to convert to PNG.** JPG compresses text and makes it fuzzy.
- **Don't skip the alt-text.** Etsy uses alt-text for SEO. Use the lines from `etsy-listing.md` section 7.

## If Canva Doesn't Work for You (Free Alternatives)

- **Photopea.com** — free Photoshop clone in browser. More flexibility, more skill required.
- **Figma.com** — free, browser-based, design-focused. Steeper learning curve.
- **Google Slides** — you already have it. Make the cover as a slide, export as PNG.
- **PowerPoint** — same idea. Insert → Shapes for the rectangles, Text for the words, Export as Image.

The Canva walkthrough above works the same way in any of these — just the buttons are different.
