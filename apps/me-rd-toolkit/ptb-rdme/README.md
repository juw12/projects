# PTB RDME Widget

LAN-shared widget for the **PTB RD ME** team. Two features in one PWA:

1. **Overtime** — daily OT submission before 16:00, Friday reveals a Saturday
   OT toggle, background scheduler posts Teams reminder cards at 14:00 and
   15:00 to colleagues who haven't replied, consolidator gets a one-click
   `.xlsx` export that matches the PTB RD ME & Packing Daily Overtime Work
   Application layout.
2. **Email Drafts** — when run on a PC with Outlook desktop, reads the
   user's local Outlook Drafts folder + inbox unread count.

## Stack

- Python 3.10+ stdlib only (`http.server`, `sqlite3`, `zipfile`, `xml`,
  `win32com` for Outlook COM)
- Vanilla HTML / CSS / JS PWA
- Zero third-party dependencies

## Quick start

```bat
run.bat
```

Then open `http://localhost:8050/` from any PC on the same LAN.

For background / silent run:
```bat
start-hidden.vbs
```
(uses `pythonw.exe`, no console window)

To stop:
```
taskkill /im pythonw.exe /f /fi "windowtitle eq PTB*"
```

## REST API

| Method | Path | Purpose |
|---|---|---|
| GET | `/api/status` | server health + today/date |
| GET | `/api/colleagues` | list of PTB RD ME colleagues |
| POST | `/api/colleagues` | upsert a colleague (admin) |
| GET | `/api/ot/today` | today's submissions + submitted set |
| GET | `/api/ot/range?start=&end=` | range query |
| POST | `/api/ot` | submit a new proposal |
| POST | `/api/ot/{id}/status` | update proposal status (consolidator) |
| GET | `/api/ot/export?date=YYYY-MM-DD` | `.xlsx` download |
| GET | `/api/email/drafts` | local Outlook drafts (only on local PC) |
| GET | `/api/email/inbox-unread` | local unread count |

## Configuration

### Teams reminder webhook

Pass `--teams-webhook https://outlook.office.com/webhook/...` to `run.bat` or
`start-hidden.vbs` (or set it in the colleagues table per person).

### Database

`data/ptb_rdme.sqlite3` is created on first run. To seed from the previous
`overtime-pulse` project:

```bat
copy apps\overtime-pulse\server\db\overtime.sqlite3 apps\ptb-rdme-widget\data\ptb_rdme.sqlite3
```

The schemas match.

## Email drafts tab — local Outlook only

The `/api/email/*` routes use `win32com` to talk to Outlook COM. This works
when the widget server runs on **the same PC as Outlook desktop**. When run
on a different LAN machine, the routes return a friendly "Outlook COM not
available" message and the rest of the widget still works.

If you want the Email Drafts tab populated automatically, run the widget on
your own PC (where Outlook is installed).

## Security

- The HTTP server binds to `0.0.0.0` so the LAN can reach it — anyone on
  the same network can submit OT. If you need access control, run behind
  a reverse proxy with auth, or change `--host` to `127.0.0.1`.
- API keys / webhook URLs live in CLI args or the colleagues table — keep
  the SQLite file inside the LAN only.

## Building a single-file .exe (no Python needed on target)

```bat
python build.py
```

Output: `dist/PTB-RDME-Widget.exe` (~14 MB, single file).

What it does:
- Bundles Python + stdlib + win32com into one file via PyInstaller
- Bundles `web/` (PWA assets) inside the .exe
- Data dir (`data/ptb_rdme.sqlite3`) is created **next to the .exe** on first run
- `data/` and `logs/` are NOT bundled — created at runtime

Distribution:
1. Zip the whole `dist/` folder (`.exe` + `data/` + `logs/`)
2. The .exe is self-contained — recipients don't need Python installed
3. First launch: tiny tk window appears with **Open widget** + **Stop** buttons
4. Default browser opens to `http://127.0.0.1:8050/`
5. Close the tk window → server stops, .exe exits

Run on the same PC as Outlook desktop to enable the **Email Drafts** tab.

Build requirements (only on the build machine, not target):
- Python 3.10+
- PyInstaller 6+ (`pip install pyinstaller`)
- Pillow (already required for icon generation)

## How the .exe finds its data

When launched:
- **Frozen** (`sys.frozen`): data lives next to the .exe at `<exe-dir>/data/ptb_rdme.sqlite3`
- **Unfrozen** (`python -m server`): data lives at `<project>/data/ptb_rdme.sqlite3`

Same for logs (`<exe-dir>/logs/widget.log` vs `<project>/logs/app.log`).

## Migration from `overtime-pulse`

The schemas are identical. To pick up where the old app left off:

```bat
xcopy apps\overtime-pulse\server\db\overtime.sqlite3 apps\ptb-rdme-widget\data\ptb_rdme.sqlite3
```

The 10 colleagues + 1 sample OT proposal in the old database will be
visible immediately.
