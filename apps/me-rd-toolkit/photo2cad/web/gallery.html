Public gallery · how to add a real part

This is the public gallery. The public build ships illustrative sample parts (tagged sample); real generated parts appear here once their output files are added. To publish one, edit gallery.json, set the part’s step / stl / render (relative or full https:// URLs) and set sample: false.

Per-part fields: name · category · shape (box | bracket | lid | gear | heatsink | flange) · units · prd · faces [· {key, label}] · render · step · stl · created · sample.
