# Shortcraft is now Hazel Shorts

Shortcraft joined Sped and the original Hazel in one app, **Hazel**. Its source now lives in
[apps/hazel](../hazel/) — web studio in [apps/hazel/web/shorts](../hazel/web/shorts/), pipeline and docs in
[apps/hazel/shorts](../hazel/shorts/).

- App: https://juw12.github.io/projects/hazel/shorts/app.html
- Web: https://juw12.github.io/projects/hazel/shorts/
- Mobile: https://juw12.github.io/projects/hazel/shorts/mobile.html

Old website addresses (`/projects/shortcraft/…`, including `channel.html` and `?sample=` links) redirect automatically.
Saved projects, voice clips and settings keep loading — the browser storage names did not change.
