# Respark - 14-Day Ship Checklist

This is a working plan to go from "idea" to "first paying client" in 14 days.

## Week 1: Setup + Build

### Day 1-2: Environment
- [ ] Install Python 3.12+ (already installed if you have Respark running)
- [ ] Set up a Gmail account for sending emails (with App Password)
- [ ] Set up a Stripe account (test mode)
- [ ] Pick a city to focus on for cold outreach

### Day 3-4: Domain Research
- [ ] Find 50+ local service businesses on Google Maps (plumbers, dentists, salons)
- [ ] Note their email addresses (check websites, social media)
- [ ] Save to `prospects.csv`
- [ ] Prioritize by: number of reviews (10+), active website, owner-operated

### Day 5-7: First Outreach Wave
- [ ] Send 10 cold emails using Template A from `sales-playbook.md`
- [ ] Send 10 more on Day 6
- [ ] Send 10 more on Day 7
- [ ] Track responses in `prospects.csv`
- [ ] Goal: 3-5 replies, 1-2 calls booked

## Week 2: Close + Deliver

### Day 8-9: Discovery Calls
- [ ] Call interested prospects (15 min each)
- [ ] Use the script from `sales-playbook.md`
- [ ] Demo the product live (your deployed URL)
- [ ] Goal: 1-2 verbal commitments

### Day 10-11: Close
- [ ] Send Stripe Checkout link to interested prospects
- [ ] Follow up 24 hours later
- [ ] Goal: 1 paying client

### Day 12-13: Onboard
- [ ] Send client their login URL + temp password
- [ ] Ask for their customer list (CSV)
- [ ] Build their campaign (customize industry template)
- [ ] Send 2 sample messages for approval
- [ ] Launch the campaign

### Day 14: Verify + Iterate
- [ ] Confirm first messages sent
- [ ] Check open rates via tracking pixel
- [ ] Schedule follow-up check-in with client
- [ ] Continue outreach to fill pipeline

---

## Success Metrics

| Day | Target |
|-----|--------|
| 7   | 30 emails sent, 3+ replies |
| 10  | 2 calls booked, 1 verbal yes |
| 14  | 1 paying client ($497 received), campaign live |

## What "done" looks like

- [ ] Stripe has your first $497
- [ ] Client has their login and uploaded customer list
- [ ] Campaign is launched, first messages sent
- [ ] You have a repeatable outreach pipeline
- [ ] Next 5 prospects are queued for next week

## Red flags (stop and fix)

- **0 replies after 20 emails:** subject lines need work. Try different angles.
- **0 calls after 5 replies:** discovery script needs practice. Roleplay with someone.
- **0 closes after 3 calls:** pricing or targeting issue. Adjust ICP.
- **Client churns in week 1:** onboarding process needs work. Stay close to first client.

---

## After Day 14

You're not done - you've started. The loop is:

```
find prospects → send emails → close calls → onboard → retain → repeat
```

Each cycle gets easier as you build case studies, testimonials, and a track record.
