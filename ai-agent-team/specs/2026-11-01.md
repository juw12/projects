# RoastMyLanding

## One-liner
Paste your SaaS landing page URL, get an AI roast plus 5 specific fixes ranked by how much they'll lift your signup rate.

## Who it's for
Indie hackers and solo founders who just shipped a landing page and have no idea whether it converts or repels. They stare at their own copy for hours and friends always say "looks great" — which is useless. They want a brutally honest outside view from someone who's seen 1,000 landing pages.

The exact frustration: "I shipped the page 3 days ago, I genuinely don't know if it's embarrassing or just okay, and I'm too close to it to judge."

## Core features (3-5 only)
1. **URL Roast** — User pastes any public landing page URL, gets a 200-word roast that names the 3 biggest problems (headline clarity, value prop timing, social proof density).
2. **Fix-It List** — 5 concrete, prioritized fixes ranked by predicted signup-rate lift. Each fix is one sentence and tells you exactly what to change and where.
3. **Shareable Roast Card** — Turns the roast into a pretty OG-image card with one click. Founders share these on Twitter for engagement; you ride the viral loop.
4. **Weekly Competitor Watch** — Email digest comparing your page to 3 competitors you picked on signup. Free tier gets one competitor, paid gets three.
5. **Score Over Time** — Each roast gives a 0-100 "Conversion Likelihood" score. Re-roast after you apply fixes and watch the number move.

## User flow
1. Visitor lands on the homepage, sees a giant input box that says "Paste your landing page URL".
2. They paste a URL and click **Roast My Page**.
3. Backend fetches the page, strips scripts/styles, sends the visible text + headline + first 200 words to the AI.
4. ~8 seconds later they see:
   - A 200-word roast in a styled card
   - The 5 prioritized fixes below it
   - The 0-100 score in the top-right
5. After 3 free roasts (anonymous, cookie-tracked), they see a paywall: "$19/mo for unlimited roasts + competitor watch".
6. Paid users also see a "Watch competitors" tab where they paste 3 URLs and get a weekly digest email.
7. Every result page has a **Share as Twitter card** button that generates an OG image.

## Pages / screens
- **`/`** — Landing page (single input + value props + 3 example roasts as testimonials)
- **`/roast/[id]`** — The roast result page. Shareable URL. Includes OG-image meta.
- **`/login`** — Magic-link email login (no password)
- **`/dashboard`** — History of all your roasts, score trend chart, "roast again" button
- **`/watch`** — Manage competitor URLs (paid only)
- **`/pricing`** — Simple: Free / Pro $19/mo

## Data needed
- User accounts (email + magic-link auth)
- Saved roasts per user (URL + result JSON + score + timestamp)
- Competitor URLs per paid user (max 3)
- Cookie-based anonymous roast counter for free tier enforcement
- OG-image cache (one PNG per roast, stored in object storage)

## Third-party services
- **Stripe** — subscriptions ($19/mo Pro tier)
- **Resend or Postmark** — transactional email (magic links, weekly digest, roast-share notifications)
- **OpenAI or Anthropic API** — the actual roast generation. Could swap to Gemini for cost.
- **Browserless or Firecrawl** — fetch + clean a landing page into text (~$0.001 per page)
- **Vercel** — hosting + OG image generation
- **Supabase** — Postgres + auth (faster than building your own)

## Vibe-coding prompt
Build RoastMyLanding: a single-page web app where the user pastes any public landing page URL into a big input, clicks "Roast My Page", and ~8 seconds later sees a styled card containing a 200-word honest roast of their page plus a numbered list of 5 specific fixes ranked by predicted signup-rate lift, plus a 0-100 "Conversion Likelihood" score in the corner. Use a dark, opinionated design — bold typography, generous whitespace, a single accent color (deep red). The result page should be shareable: include Open Graph meta tags so posting the URL on Twitter/Slack shows a generated card image with the score and the product name. Anonymous users get 3 free roasts via a cookie counter; beyond that show a paywall. Include a `/pricing` page with one paid tier at $19/mo. Stack: Next.js (App Router), Tailwind CSS, Supabase for auth + DB, Stripe Checkout for payments, Resend for emails, and either OpenAI or Anthropic's API as the AI backend. Ship a working demo today: even if the AI roast is mocked with a template at first, the full UX, payment flow, and share-card generation should be real.

## Out of scope (for v1)
- Mobile app (web-only)
- Multi-language support (English only)
- Custom branding / white-label for agencies
- A/B testing of roast styles against each other
- Detailed heatmaps or scroll-tracking analytics
- Public API for embedding the roaster in someone else's site
- Anything requiring scraping of authenticated pages
