# Saltbridge — Bilingual EN/中文 Freelance Services

> *Preserving value across languages.*

The complete launch package for selling bilingual translation + copywriting services on Fiverr, Upwork, and via cold outreach to Chinese e-commerce sellers.

**Capital required:** $0
**Time budget:** 1-2 hours/day
**Target:** $500-2000/month within 90 days, with realistic path to $3000/month by month 6.

---

## Why "Saltbridge"

Salt preserves. Bridges connect. Saltbridge is the work of carrying essential value across the language line — without losing what makes the original worth reading.

Every deliverable (translation, listing, email) is built around one principle: the meaning has to survive the crossing.
