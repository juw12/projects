# Day 1 Execution Kit

Everything you need to go from $0 to "3 Fiverr gigs live" in your first 60-90 minutes. Read this before you start.

---

## Hour 0: Setup (5 min)

Have these open in tabs before you touch Fiverr:
1. `freelancing-launch/01-fiverr-gigs.md` — the 3 gigs, already written
2. This file — what to click on Fiverr
3. **Canva** (free, browser or app) — for gig images
4. A notepad — for any "save for later" tweaks

You'll also need:
- A dedicated email for freelance (Gmail recommended)
- Government ID for Fiverr's identity verification (passport or driver's license — non-Thai IDs work but verification can take longer; have a backup method ready)
- A way to receive payment — PayPal or bank account that accepts USD

## Hour 0–1: Build the 3 gig images (30 min in Canva)

Fiverr requires a **1280×769 px** image per gig. Canva free tier has the Fiverr Gig template built in.

**In Canva:**
1. New design → search "Fiverr Gig" → pick any template, replace the contents
2. Or: Custom size → 1280 × 769 px, blank canvas

Design rules for all 3:
- **Big, readable text** (5-7 words max). The text sells in 1 second when buyers scroll search results.
- **One benefit** (not a list). "Native-grade" / "24h turnaround" / "Both languages, native."
- **Strong contrast.** Light text on dark background, or dark text on white.
- **Your face or a clean icon, never both.** A clean icon feels more "serious service"; your face feels more "personal freelancer." Both work. Pick one per gig and stay consistent within the gig.
- **Skip the stock-photo clichés.** No handshakes, no lightbulbs, no generic office shots.

### Gig 1 — Translation

Suggested layout:
- Left side: a large Chinese character or phrase rendered cleanly (e.g., 翻译 / 翻譯) next to the English word "Translation"
- Right side: 2-line value prop — **"EN ↔ 中文 · Native both sides · 24h"**
- Color palette: ink black + newspaper red (think The Economist)
- Canva search terms: "minimal editorial," "Chinese typography," "translation services"

### Gig 2 — Product Descriptions (Amazon / Etsy / Shopify)

Suggested layout:
- A mock product card (Amazon-style tile) with your rewritten headline
- 2-line value prop — **"Listings that convert, not translate"**
- Color palette: deep teal + cream, or charcoal + accent yellow
- Canva search terms: "ecommerce product," "amazon listing," "minimal product card"

### Gig 3 — Bilingual Email

Suggested layout:
- Split-screen mock — half in English, half in 中文 — both saying the same thing
- 2-line value prop — **"One campaign. Both markets. Native."**
- Color palette: white + bold accent (cobalt or emerald), clean sans-serif
- Canva search terms: "email marketing split," "bilingual layout," "newsletter"

Export each as PNG, 1280×769 px. Keep them under 500 KB (Fiverr's limit is generous but smaller uploads faster).

## Hour 1: Post Gig 1 on Fiverr (15 min)

Go to **fiverr.com** → log in with your new freelance email → click your avatar → **"Become a Seller"** (if you haven't already) → complete the onboarding.

Fiverr onboarding has 5 stages. Skip everything optional, complete everything required (identity, payout, language). Don't add a "skill test" yet — focus on getting gigs live first.

After onboarding:
1. **Seller dashboard → Gigs → Create a New Gig**
2. **Step 1 — Overview:**
   - **Gig title:** paste from `01-fiverr-gigs.md` Gig 1, exactly as written
   - **Category:** "Writing & Translation" → "Translation" → "Chinese (Simplified) to English" (or English to Chinese — pick one; you can edit later)
   - **Service type:** "Translation"
   - **Subcategory:** "General"
3. **Step 2 — Scope & Pricing:**
   - Copy the 3 tiers (Basic/Standard/Premium) from `01-fiverr-gigs.md` table, exactly
   - Set delivery times and revision counts as shown
   - Turn ON the "Fast delivery" toggle ONLY if you can honestly commit to the rush timeline; otherwise leave OFF (false promises hurt reviews)
4. **Step 3 — Description & FAQ:**
   - **Description:** paste the entire description block from `01-fiverr-gigs.md`. The line breaks and bullets carry over.
   - **FAQ:** paste the 5 FAQ items, one per row
5. **Step 4 — Requirements:** paste the 7 buyer-questions block from `01-fiverr-gigs.md`
6. **Step 5 — Gallery:**
   - **Upload your gig image** (the Canva export, 1280×769 px)
   - (Optional) Add 1-2 more slides if you want; not required
   - **Video:** skip for Day 1 — videos help but aren't required, and adding one is a Day 7+ optimization
7. **Publish.** Fiverr reviews new gigs in <24h. You'll get an email when it goes live.

**Repeat for Gigs 2 and 3.** Same flow, paste from `01-fiverr-gigs.md`, upload the matching Canva image. Gigs 2 and 3 should each take ~10 min once you've done the first.

## Hour 1.5: Set up the tracking sheet (10 min)

Open **sheets.google.com** → new spreadsheet → name it "Freelance Tracker."

Import these columns (copy the header row below into row 1):

```csv
brand,contact_channel,handle,product_url,date_sent,response_status,followup_date,notes
```

Then add a second sheet (bottom tab) named **"Upwork Proposals"** with:

```csv
job_title,job_url,proposal_sent_date,response_status,interview_date,notes
```

You'll log one row per outreach message and one row per Upwork proposal. After 7 days you'll have enough data to see what's working.

**Bookmark the sheet on your phone.** You'll add rows from your phone during the day.

## When a buyer messages you (the only thing you should ALWAYS do)

Response time is a Fiverr ranking signal. **Reply within 2 hours, ideally within 30 min.** Even if the reply is just: *"Got it — I'll send a short proposal within 24h."*

When a buyer sends a real project brief, paste their message into this session and I'll draft the deliverable for your review. You send it under your name.
